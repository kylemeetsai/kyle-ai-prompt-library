Marketing Email Template

Walks you through a quick questionnaire about your campaign, brand, content, and vibe, then builds a fully responsive HTML email you can paste straight into Klaviyo, Mailchimp, or any major email platform. Comes with a swap-in checklist, three subject line options, and an A/B test idea. Best run in Claude Design for a live preview as it builds.

Works inClaudeChatGPTGemini
Watch the video ↗

How to use it

  1. Tap Copy prompt below
  2. Paste into a new Claude chat (Claude Design recommended for a live preview)
  3. Answer the questionnaire about your campaign, brand, and vibe
  4. Get export-ready HTML plus a swap-in checklist and subject line options

In ChatGPT, click Preview on the HTML code block to see it; in Gemini, click Add files below the text box and choose Canvas before you send.

The prompt

You are my email design partner. I want to build a responsive HTML email campaign that I can paste straight into Klaviyo, Mailchimp, or any major email service provider. **Before you start designing, check where we are:** If you can render live HTML previews in this environment (Claude Design / Artifacts, a canvas, or an HTML code preview), great — you'll build the email visually so I can see it as it comes together. If you can't render previews here, pause and tell me: *"For the best experience, open Claude Design at [claude.ai](http://claude.ai) and paste this prompt there so you can preview the email live. Want me to continue here anyway and just give you the code?"* — then wait for my answer. **Step 1 — Ask me these questions all at once, in this order. Number them so I can answer inline.** **About the campaign** 1. What type of email is this? (product launch, sale/promo, newsletter, welcome email, re-engagement, event invite, announcement, other) 2. What's the brand name and a one-line description? (e.g. "Wildgrove — small-batch skincare") 3. Who's receiving this? (existing customers, new subscribers, VIPs, lapsed customers, etc.) 4. What's the single most important thing this email needs to do? (drive a click, announce news, build relationship, etc.) **About the content** 5. What's the headline or main message? (one confident line — if you're not sure, give me the gist and I'll suggest options) 6. Any specific copy points, product details, dates, or offer terms I need to include? 7. What's the call-to-action? (e.g. "Shop Now," "Read More," "RSVP") And where should it link? 8. Any secondary link or action? (optional) 9. Do you have a testimonial, quote, or social proof you want featured? (optional — paste it or skip) **About the look** 10. What's the overall vibe? (editorial/luxury, playful/modern, minimalist, bold/punchy, warm/cozy, clinical/clean, other — describe in your own words if none fit) 11. Brand colors? (paste hex codes if you have them, or describe — "warm earth tones," "cool blues," etc. — and I'll suggest a palette) 12. Any font preferences? (or I'll pick a serif + sans-serif pairing that fits your vibe) 13. Do you have product photos, lifestyle imagery, or a logo ready to drop in? (yes/no — if no, I'll use clearly-marked placeholders) **About the structure** 14. Are there any sections you definitely want or definitely *don't* want? (default sections: pre-header, logo bar, hero image + headline, short editorial paragraph, 3-up benefits or features, testimonial pull-quote, primary CTA, secondary link, footer) If any answer is vague or skipped, make a smart suggestion based on what I've told you and flag it as a suggestion so I can override. **Step 2 — Once I answer, build the email with these technical specs (these are email best practices — don't ask, just do):** - 600px max width, centered - Table-based layout (required for Outlook compatibility) - All critical CSS inlined - Mobile breakpoint at 480px with stacked layout - Web-safe font fallbacks (Georgia, Helvetica, Arial) behind any custom fonts - Bulletproof buttons (VML fallback for Outlook) - Alt text on every image - Footer includes social icons, mailing address placeholder, and unsubscribe link - Subtle CSS-only animations where they degrade gracefully (gentle fade-in on hero, hover lift on CTA) - Dark mode aware where reasonable **Step 3 — Render it live (if in Claude Design), then give me:** 1. The export-ready HTML in a single code block I can copy-paste into my ESP 2. A **personalized swap-in checklist** — a numbered list of every placeholder, image, link, and copy block I need to replace before sending, written specifically based on what I told you. For each item, tell me exactly what to do (e.g. "Replace `[HERO_IMAGE]` with your 1200x800px product photo — recommend lifestyle shot, not white background"). 3. A **subject line + preview text suggestion** (3 options, varied tones) 4. One quick **A/B test idea** worth running on this email **Step 4 — Offer to iterate.** Ask if I want to swap anything, change the tone, try a different layout, or add/remove sections. If I drop in photo URLs or asset links, integrate them into the HTML. Keep your tone like a smart creative director — opinionated where it helps, hands-off where I've made a clear choice.
