# kylemeetsai.com

Kyle's link-in-bio site: free prompts from every KyleMeetsAI video, the videos themselves, and
how to work together.

- Prompts live in `content/prompts/`, one text file each.
- `python3 tools/build.py` builds the site; `python3 tools/serve.py` previews it locally.
- Merging into `main` publishes it through Cloudflare Pages.

Full working guide: `CLAUDE.md`.
